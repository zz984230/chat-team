第一阶段实施范围（后端）

包含

  • Supervisor 进程管理
  • Agent 工作流引擎
  • Claude CLI 子进程调度
  • Obsidian Vault 文件存储
  • FastAPI REST + WebSocket API
  • 四种默认角色工作流

不包含（后续阶段）

  • PixiJS 前端可视化
  • 向量搜索 (QMD)
  • 自定义工作流编辑器
  • 多用户支持
