配置文件

settings.yaml
server:
  host: "0.0.0.0"
  port: 8000
  cors_origins: ["http://localhost:3000"]

agent:
  max_concurrent: 5
  timeout_seconds: 300
  retry_count: 1
  work_dir: "/tmp/agentoffice"

vault:
  path: "./vault"

workflow:
  default_mode: "default"        # default | brainstorm
  brainstorm_rounds: 3

logging:
  level: "INFO"
  file: "./logs/agentoffice.log"

启动流程

Application Bootstrap
1. 加载配置
   config = load_config("settings.yaml")

2. 初始化 Vault
   vault_mgr = VaultManager(config.vault.path)
   vault_mgr.ensure_structure()      # 确保 agents/sessions/ 等目录存在
   vault_mgr.load_agent_definitions() # 加载 agents/*.yaml

3. 创建组件
   pool = AgentPool(config.agent)
   ws_manager = WebSocketManager()
   engine = WorkflowEngine(pool, vault_mgr, ws_manager)

4. 创建 FastAPI
   app = create_app(config, engine, ws_manager)

5. 启动服务
   uvicorn.run(app, host=config.server.host,
                     port=config.server.port)

开发命令

# 安装依赖
